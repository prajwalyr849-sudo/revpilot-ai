# RevPilot AI — Razorpay Internship Portfolio Demo

**Built & Designed by Prajwal Y R**

RevPilot AI is a revenue intelligence portfolio project for customer segmentation, targeting, campaign prediction, what-if analysis, AI-assisted campaign creation, Customer 360, analytics, ML transparency, and exports.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Google Colab
Open the included `.ipynb` notebook and run the cells from top to bottom.

For a public demo from Colab, use the Cloudflare Quick Tunnel commands from the notebook/session:
```bash
/content/cloudflared tunnel --url http://127.0.0.1:8501 --no-autoupdate
```

## Note
The ML training labels are synthetic for demonstration because the demo dataset does not contain historical campaign outcome labels. Replace them with real outcomes before production use.
