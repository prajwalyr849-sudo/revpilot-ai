# RevPilot AI --- Revenue Intelligence

### AI-powered merchant revenue growth agent
:::

------------------------------------------------------------------------

## 🚀 Overview

RevPilot AI is a revenue intelligence workspace designed to help
businesses understand customer value, identify high-value opportunities,
prioritize customers, and analyze revenue performance.

## ✨ Features

-   📊 Executive Revenue Dashboard
-   👥 Customer Intelligence
-   🎯 AI Target Customers
-   🔮 Campaign Prediction
-   📈 Revenue Analytics
-   📁 CSV / XLSX / XLS dataset upload
-   🌙 Modern dark-mode interface
-   📌 Live dataset-driven analytics

## 🛠️ Tech Stack

-   Python
-   Streamlit
-   Pandas
-   Plotly
-   Machine Learning / AI

``` bash
pip install -r requirements.txt
streamlit run app.py
```

## 📊 Data

Upload a CSV, XLSX, or XLS file through the application to activate the
revenue intelligence dashboard.

RevPilot AI does not require fake preloaded customer data.
